## 1. 前置软件安装清单

| 序号 | 软件 | 最低版本 | 用途 | 下载/安装方式 |
|------|------|----------|------|--------------|
| 1 | Python | 3.11+ | 后端运行环境 | https://www.python.org/downloads/ |
| 2 | Node.js | 18+ | 前端构建运行 | https://nodejs.org/ (推荐LTS) |
| 3 | MySQL | 8.0+ | 业务数据存储 | https://dev.mysql.com/downloads/mysql/ |
| 4 | Milvus Standalone | 2.4+ | 向量检索存储 | https://github.com/milvus-io/milvus/releases |

### 1.1 Python 安装验证

```bash
python --version   # 应显示 Python 3.11.x 或更高
pip --version      # 应显示 pip 24.x 或更高
```

Windows 用户安装时勾选 "Add Python to PATH"。

### 1.2 Node.js 安装验证

```bash
node --version  # 应显示 v18.x 或更高
npm --version   # 应显示 9.x 或更高
```

### 1.3 MySQL 8.0 安装与初始化

#### Windows

1. 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
2. 安装时选择 "Server only"，设置 root 密码
3. 安装完成后 MySQL 自动作为 Windows 服务运行

```cmd
:: 验证MySQL运行
net start | findstr MySQL

:: 如果未启动
net start MySQL80

:: 命令行登录验证
mysql -u root -p
```

#### Mac

```bash
# 安装
brew install mysql@8.0

# 启动服务
brew services start mysql@8.0

# 设置root密码（首次）
mysql_secure_installation
```

#### Linux (Ubuntu/Debian)

```bash
# 安装
sudo apt update
sudo apt install mysql-server-8.0

# 启动
sudo systemctl start mysql
sudo systemctl enable mysql

# 设置root密码
sudo mysql_secure_installation
```

#### 创建数据库

MySQL 启动后，创建项目所需数据库：

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS `rag_kb`
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

-- 查看确认
SHOW DATABASES LIKE 'rag_kb';
```

> **说明**：数据库表结构会在后端首次启动时通过 SQLAlchemy `Base.metadata.create_all` 自动创建，无需手动执行 init.sql。init.sql 仅作为参考文档。

### 1.4 Milvus Standalone 安装与启动

本系统使用 Milvus Standalone（单机版），**不使用 Docker**。

#### 下载

前往 https://github.com/milvus-io/milvus/releases 下载对应系统的最新版本。

#### Windows

```cmd
:: 解压下载的 milvus-standalone-windows-amd64.zip
:: 进入解压目录，运行：
milvus run standalone

:: 首次启动会自动下载依赖并初始化，
:: 看到 "Milvus standalone started" 即启动成功
```

#### Mac

```bash
# 下载后解压，进入目录
./milvus run standalone
```

#### Linux

```bash
# 下载后解压，进入目录
./milvus run standalone
```

#### 验证 Milvus 启动

```bash
# 检查端口是否在监听
curl http://localhost:19530/healthz
# 应返回：OK
```

> **重要**：Milvus Standalone 默认监听 `localhost:19530`，数据存储在 `~/.milvus/` 目录。

## 2. 环境变量配置指南

### 2.1 创建 .env 文件

```bash
# 项目根目录下
cp .env.local .env
```

### 2.2 必须修改的配置项

编辑 `.env` 文件，修改以下**必填项**：

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| `MYSQL_PASSWORD` | MySQL root 密码 | `your-mysql-password` |
| `TONGYI_API_KEY` | 阿里云灵积 API Key | `sk-xxxxxxxxxxxxx` |
| `DEEPSEEK_API_KEY` | DeepSeek API Key | `sk-xxxxxxxxxxxxx` |

### 2.3 API Key 申请指南

#### 阿里通义 Embedding API

1. 访问 https://dashscope.aliyun.com/
2. 登录阿里云账号 → 开通"灵积模型服务"
3. 在"API-KEY管理"页面创建 Key
4. 模型：text-embedding-v3，计费约 0.0008 元/千tokens

#### DeepSeek Chat API

1. 访问 https://platform.deepseek.com/
2. 注册/登录 → API Keys 页面
3. 创建 Key
4. 模型：deepseek-chat，输入 0.001 元/千tokens，输出 0.002 元/千tokens

### 2.4 计费单价配置

`.env` 中的单价参数直接影响费用报表的实时计算，可按实际价格调整：

```bash
TONGYI_EMBEDDING_TOKEN_PRICE=0.0008   # 向量化单价（元/token）
DEEPSEEK_INPUT_TOKEN_PRICE=0.0010     # LLM输入单价（元/token）
DEEPSEEK_OUTPUT_TOKEN_PRICE=0.0020    # LLM输出单价（元/token）
```

> 修改单价后刷新费用报表页面即可看到重新计算的结果，无需重启服务。

## 3. 分步启动

**启动顺序不可颠倒：MySQL → Milvus → 后端 → 前端**

### 3.1 步骤1：启动 MySQL

确保 MySQL 服务已运行且可连接。

```bash
# 验证连接
mysql -h localhost -P 3306 -u root -p -e "SELECT 1"
```

### 3.2 步骤2：启动 Milvus Standalone

打开新终端窗口：

```bash
# 进入 Milvus 解压目录
./milvus run standalone

# 验证
curl http://localhost:19530/healthz
```

> Milvus 窗口需保持运行，关闭即停止服务。

### 3.3 步骤3：启动后端服务

#### Windows

```cmd
cd rag-kb-system
scripts\run_backend.bat
```

或在资源管理器中双击 `scripts\run_backend.bat`。

#### Mac / Linux

```bash
cd rag-kb-system
bash scripts/run_backend.sh
```

**启动后会自动：**
1. 检查 Python 环境和 .env 配置
2. 创建/激活虚拟环境
3. 安装 pip 依赖
4. 创建 uploads/crawls/logs 目录
5. 自动建表 + 创建超管账号
6. 启动 uvicorn 在 `http://localhost:8000`

**验证后端启动成功：**

```bash
curl http://localhost:8000/api/health
# 返回：{"status":"ok","service":"rag-kb-system"}
```

访问 API 文档：http://localhost:8000/docs

### 3.4 步骤4：启动前端开发服务器

#### Windows

```cmd
cd rag-kb-system
scripts\run_frontend.bat
```

#### Mac / Linux

```bash
cd rag-kb-system
bash scripts/run_frontend.sh
```

**启动后会自动：**
1. 检查 Node.js 环境
2. 安装 npm 依赖（首次）
3. 启动 Vite 开发服务器在 `http://localhost:5173`

### 3.5 一键启动（可选）

确认 MySQL 和 Milvus 已启动后：

| 系统 | 命令 |
|------|------|
| Windows | `scripts\run_all.bat` |
| Mac/Linux | `bash scripts/run_all.sh` |

### 3.6 停止服务

| 系统 | 命令 |
|------|------|
| Windows | `scripts\stop_all.bat` |
| Mac/Linux | `bash scripts/stop_all.sh` |

> 停止脚本只关闭前后端进程，MySQL 和 Milvus 需手动停止。

## 6. 本机存储路径说明

### 6.1 项目目录结构

```
rag-kb-system/
├── .env                    # 环境变量（从.env.local复制并填写）
├── .env.local              # 环境变量模板
├── sql/init.sql            # 数据库初始化SQL（参考用）
├── scripts/                # 启动/停止脚本
├── backend/
│   ├── app/                # Python源码
│   ├── data/
│   │   ├── uploads/        # ★ 上传文件存储
│   │   └── crawls/         # ★ 爬虫缓存文件
│   ├── logs/               # ★ 后端运行日志
│   ├── venv/               # Python虚拟环境（启动脚本自动创建）
│   └── requirements.txt    # Python依赖清单
├── frontend/
│   ├── src/                # Vue3源码
│   ├── node_modules/       # npm依赖（启动脚本自动安装）
│   ├── dist/               # 生产构建产物
│   └── package.json        # npm依赖清单
└── docs/                   # ★ 文档目录
```

### 6.2 文件上传存储

- **路径**：`backend/data/uploads/`
- **命名规则**：UUID + 原始后缀名（如 `a1b2c3d4-xxxx-xxxx-xxxx-xxxxxxxxxxxx.pdf`）
- **原始文件名**：存储在 documents 表的 `original_filename` 字段
- **配置文件键**：`.env` 中 `UPLOAD_DIR=./data/uploads`

### 6.3 爬虫缓存存储（二期功能）

- **路径**：`backend/data/crawls/`
- **配置文件键**：`.env` 中 `CRAWL_DIR=./data/crawls`

### 6.4 后端日志

- **输出方式**：控制台标准输出 + 日志文件
- **日志目录**：`backend/logs/`
- **日志级别**：debug（`.env` 中 `APP_DEBUG=true` 时）或 info（生产模式）

### 6.5 MySQL 数据

- 数据存储在 MySQL 默认数据目录
  - Windows：`C:\ProgramData\MySQL\MySQL Server 8.0\Data\`
  - Mac（Homebrew）：`/usr/local/var/mysql/`
  - Linux：`/var/lib/mysql/`

### 6.6 Milvus 向量数据

- **默认路径**：`~/.milvus/`（用户目录下）
- **数据量**：每个知识库一个 Collection，向量维度 1536
