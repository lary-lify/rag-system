| `--brand-900` | `#1e3a8a` | 最深蓝、极少使用 |

### 2.2 语义色彩

| Token | 色值 | 用途 |
|-------|------|------|
| `--success-500` | `#22c55e` | 成功状态、入库成功 |
| `--warning-500` | `#f59e0b` | 警告、处理中状态 |

| `--info-500` | `#3b82f6` | 信息提示 |

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| `--gray-0` | `#ffffff` | `#0f172a` | 页面背景 |
| `--gray-50` | `#f8fafc` | `#1e293b` | 二级背景、表头 |

- **浅色主题**：白底 + 蓝点缀，高对比度，适合明亮办公环境
- **深色主题**：深蓝黑底 `#0b1120`，降低眼部疲劳，适合暗光环境
- 所有色彩通过 CSS 变量自动切换，开发者只需使用 Token 名称

## 六、组件规范

### 6.1 按钮

| 变体 | 使用场景 |
|------|---------|
| `btn-primary` | 主操作：确认创建、登录、保存 |
| `btn-secondary` | 次要操作：取消、导出、筛选 |
| `btn-ghost` | 表格内操作：重命名、预览、删除 |
| `btn-danger` | 高危操作确认：删除确认按钮 |

**尺寸**：`btn-sm`（28px）、默认（34px）、`btn-lg`（40px）

### 6.2 表单

- 标签在上，输入框在下（`gap: 4px`）
- 聚焦：蓝色边框 + 3px 浅蓝外发光
- 错误：红色边框 + 红色外发光
- 提示文字：12px 灰色置于输入框下方

### 6.3 表格

- 表头：浅灰背景、12px 大写字母、加粗
- 行悬浮：浅灰背景高亮
- 单元格内边距：12px 横向 × 12px 纵向
- 分页：底部居中，当前页蓝色高亮

### 6.4 弹窗

- 最大宽度 520px（标准）/ 720px（大型）
- 头部：标题 + 关闭按钮，底部有分割线
- 内容区：可滚动
- 底部：按钮右对齐
- 动画：淡入 + 上滑（`opacity + translateY`）

### 6.5 状态标签 (Badge)

```
入库成功 — 绿色底 + 绿点
处理中   — 橙色底 + 橙点
入库失败 — 红色底 + 红点
信息     — 蓝色底 + 蓝点
默认     — 灰色底 + 灰点
```

## 八、动效规范

| 场景 | 动效 | 参数 |
|------|------|------|
| 页面切换 | 即时切换（无动画） | — |
| 弹窗出现 | 淡入 + 上滑 8px | `0.2s ease-out-expo` |
| 消息气泡 | 淡入 + 上滑 8px | `0.3s ease-out-expo` |
| Toast 通知 | 右侧滑入 | `0.3s ease-out-expo` |
| 按钮点击 | 缩放至 98% | `0.15s ease-out-quart` |
| 悬浮态 | 阴影加深 + 边框变色 | `0.15s ease-out-quart` |
| 打字指示器 | 循环弹跳 | `1.4s ease infinite` |
| 停止生成按钮 | 呼吸闪烁 | `1.5s ease infinite` |

## 九、深色主题适配

深色主题通过 `[data-theme="dark"]` 选择器覆盖所有 Token：

1. **背景色反转**：浅色白底 → 深色 `#0b1120` 蓝黑底
2. **灰度颠倒**：`gray-0` 和 `gray-900` 互换
3. **品牌色上浮**：深色模式下蓝色更亮（`#60a5fa` 替代 `#2563eb`）
4. **边框加深**：分割线对比度提升
5. **阴影加重**：暗色环境下需要更深的阴影产生层次感
6. **侧边栏更暗**：`#060b16` 与内容区形成区分

## 十、可访问性 (WCAG AA)

| 检查项 | 状态 |
|--------|------|
| 正文对比度 ≥ 4.5:1 | ✅ 浅色模式 `#0f172a` on `#ffffff` = 15.4:1 |
| 大文字对比度 ≥ 3:1 | ✅ 统计数值 30px 满足 |
| 聚焦指示器 | ✅ 2px 蓝色 outline + 2px offset |
| 键盘导航 | ✅ Tab 切换、Enter 确认、Esc 关闭弹窗 |
| 触摸目标 ≥ 44px | ✅ 发送按钮、弹窗关闭按钮满足 |
| 自定义滚动条 | ✅ 6px 宽度，满足视觉需求 |

### 使用方式

1. 用浏览器直接打开 `index.html` 查看所有页面
2. 点击左侧导航切换页面
3. 点击左下角主题按钮切换浅色/深色模式
4. 在智能问答页面输入文字并按 Enter 体验流式对话模拟
5. 点击上传区域体验切分策略选择弹窗
6. 点击表格中的"清空向量"/"删除"等按钮体验二次确认弹窗
